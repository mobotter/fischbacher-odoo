Put records into sub-tree

Use-Cases:

  • Web Api with static header informations

Documentation:

Input

[
    {
        "name": "product 1"
    },
    {
        "name": "product 2"
    }
]

Result

[
    {
        "header_informations": {
            "version": "1.0"
        },
        "product": {
            "name": "product 2"
        }
    }
]

Mappings

Source Action Destination Details
object header_informations
Source Action Destination Details
'1.0' eval version
object product
Source Action Destination Details
name direct name
