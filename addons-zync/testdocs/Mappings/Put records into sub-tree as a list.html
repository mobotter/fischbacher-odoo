Put records into sub-tree as a list

"

Use-Cases:

  • Web Api with static header informations

Documentation:

Takes a list of records and puts it into chosen places as list again.

Input

[
    {
        "name": "product 1"
    },
    {
        "name": "product 2"
    }
]

Result

[
    {
        "header_informations": {
            "version": "1.0"
        },
        "products": [
            {
                "name": "product 1"
            },
            {
                "name": "product 2"
            }
        ]
    }
]
