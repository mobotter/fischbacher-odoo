## Installation

- Setup the addons paths; in our stable repository all used modules are collected and put
  into one directory, so just add this directory like

  addons_zync

- This is the collected requirements.txt of all used modules

  - oauthlib
  - openpyxl
  - pymssql
  - pymysql
  - pyodbc
  - pypdf
  - pysftp
  - pyyaml
  - requests
  - requests_oauth2client>1.5.0
  - requests_oauthlib
  - sarge
  - selenium
  - snowflake_sqlalchemy
  - sqlalchemy
  - sqlalchemy_utils
  - webdavclient3
  - xmltodict
  - zeep
